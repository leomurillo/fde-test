Load a file

The file stays on your machine: keep it outside the repository (or in private/, which git ignores). The app stores the parsed test in its local database and pins every item's version when you load it.

File format 
name: Practice run
mode: end              # end: results after the last part · realtime
parts:
  - title: Part 1
    time_limit_min: 8  # or time_limit_s; omit for no limit
    items: [D4-101, D6-105, D2-103]
  - title: Part 2
    time_limit_min: 5
    items: [D7-102, D9-104@1]   # id@version pins a version

Items keep the order you list. Options are shuffled. An item may appear only once in a test.
